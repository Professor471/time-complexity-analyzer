    Times real JavaScript versions of four algorithms with performance.now() on growing random arrays.

    Press Run test. Each algorithm runs on 8 input sizes up to the largest n.
    Linear search · O(n)
    Time grows in a straight line. Double n, double the time.
    Binary search · O(log n)
    Almost flat. Doubling n adds a single extra step.
    Bubble sort · O(n²)
    Doubling n roughly quadruples the time.
    Merge sort · O(n log n)
    Slightly more than linear. Far below bubble sort at large n.

    Asymptotic notations

    O
    Big-OUpper bound · worst case
    f(n) ≤ c·g(n)
    Ω
    Big-OmegaLower bound · best case
    f(n) ≥ c·g(n)
    Θ
    Big-ThetaTight bound · exact rate
    c₁g(n) ≤ f(n) ≤ c₂g(n)
    o
    little-oStrictly slower growth
    f(n) / g(n) → 0
